# 21 — Draw Arena Accessibility

## Recursos aplicados
- suporte a `prefers-reduced-motion`
- legibilidade de texto e grupos
- controles acessíveis e claros
- progress indicator sem depender apenas de cor
- redução de animação em ambientes com menor conforto visual

## Resultados
A apresentação permanece compreensível mesmo quando a experiência visual é simplificada.
