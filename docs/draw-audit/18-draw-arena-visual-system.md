# 18 — Draw Arena Visual System

## Estética
- arena central de destaque
- iluminação premium em tons grafite, azul e dourado
- contraste forte para equipe selecionada
- painel de grupos com identidade esportiva
- progress indicator para acompanhar o sorteio

## Elementos visuais
- urna central
- bolas ou identificadores da equipe
- grupos em posições laterais
- destaque de equipe em hero reveal
- HUD discreto de progresso

## Objetivo
Criar a sensação de evento esportivo oficial, sem perder legibilidade nem clareza de informação.
